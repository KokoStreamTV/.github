# KokoStreamTV

KokoStreamTV is the planned GitHub home for **Koko**, LizardByte's self-hosted media server written in Rust.
Koko is still under development. This project organization is part of [LizardByte](https://github.com/LizardByte),
with the same shared community.

## Coming to this organization

[Koko](https://github.com/LizardByte/Koko) will move from `LizardByte/Koko` to `KokoStreamTV/Koko` once migration
preparations are complete. Until then, development and project updates remain in the current repository.

The planned project website is `koko.lizardbyte.dev`. Project links will be updated as the migration progresses.
